# Amazon Product Review Sentiment Analysis Using Tableau

## Project Overview
This project analyzes Amazon customer reviews using Tableau.

The dashboard helps understand:
- Customer satisfaction
- Positive and negative sentiments
- Product ratings
- Review trends

---

## Tools Used
- Tableau Public
- Excel
- CSV Dataset

---

## Features
- Sentiment Analysis
- Ratings Distribution
- Pie Chart Visualization
- Interactive Dashboard

---

## Dataset
Amazon Alexa Reviews Dataset

---

## Insights
- Most customers gave positive reviews.
- 4-star and 5-star ratings were highest.
- Negative reviews mainly mentioned connectivity issues.
